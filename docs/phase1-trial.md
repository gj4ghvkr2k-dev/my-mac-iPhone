# 第1段階の動作確認（MacHost と iOSClient）

Mac 側アプリ（MacHost）と iPhone／iPad 側アプリ（iOSClient）を実機で動かし、つないで確かめるための手順です。
Xcode の準備（XcodeGen、Team ID の設定）は [M2 検証の手順](m2-probe.md) の「準備」と同じです。

## 1. ビルドと起動

1. Xcode のプロジェクトを作り直します（ターゲットが増えたため）。

   ```bash
   xcodegen generate
   ```

2. **Mac**：スキーム `MacHost`、実行先「My Mac」で実行します。
   - メニューバーにディスプレイのアイコンが出ます。Dock には出ません。
   - メニューに「許可が必要です」と出たら、「画面収録」と「アクセシビリティ」を許可します。許可したあと、MacHost を一度終了して起動し直してください。
   - 許可が効かないときは、システム設定で一覧から MacRemote を一度削除してから、もう一度許可してください。ビルドし直すと、macOS が別のアプリとみなすことがあります。
3. **iPhone／iPad**：スキーム `iOSClient`、実行先を自分の端末にして実行します。

## 2. 端末の登録（初回だけ）

1. Mac のメニューバーのアイコン →「iPhone／iPad を追加…」を選び、QR コードを表示します。
2. iPhone で右上の ＋ を押し、QR コードを読み取ります。
3. 「◯◯を探しています…」のあと、自動で接続して登録されます。Mac の QR コードの画面に「登録しました」と出れば完了です。
4. 登録が終わると、そのまま Mac の画面が表示されます。

2回目からは、一覧の Mac をタップするだけでつながります。

## 3. 操作

画面上部のツールバーで、次の操作ができます。
- 切断
- キーボードを開く
- 操作モードの切り替え（トラックパッド／直接タッチ）
- 等倍に戻す
- モニターの切り替え（2台以上あるとき）
- 画質
- fps と往復の遅延の表示

| 操作 | トラックパッドモード（iPhone の初期値） | 直接タッチモード（iPad の初期値） |
|---|---|---|
| 1本指タップ | 左クリック（素早く2回でダブルクリック） | その位置を左クリック |
| 2本指タップ | 右クリック | その位置を右クリック |
| 1本指ドラッグ | カーソルを動かす | その位置からドラッグ |
| 長押ししてから動かす | ドラッグ | （長押しで）その位置を右クリック |
| 2本指ドラッグ | スクロール（離すと慣性で続く） | 同じ |
| ピンチ | 手元の表示を拡大・移動 | 同じ |
| 3本指で左右にスワイプ | デスクトップの切り替え | 同じ |
| 3本指で上にスワイプ | Mission Control | 同じ |

**キーボード**
- 日本語は iPhone 側で変換し、確定した文字が Mac に入ります。変換中の文字は、キーボードの上のバーに表示されます。
- 特殊キーのバーには、⌘ ⌥ ⌃ ⇧ esc tab ⌦ 矢印 fn（F1〜F12）、Spotlight、英数、かな があります。
- ⌘ などの修飾キーは、1回押すと次の1文字だけ、2回押すと解除するまで有効です（例：⌘ を押してから c で、⌘C）。
- **iPad の外付けキーボード**：キーをそのまま Mac に送ります。日本語の変換は Mac 側で行います。
- **iPad のトラックパッド・マウス**：ポインターの位置がそのまま Mac のカーソルの位置になります。クリック、右クリック、ドラッグ、スクロールにも対応しています。

## 4. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| iPhone の一覧で「見つかりません」になる | Mac で MacHost が起動しているか。同じ Wi-Fi にいるか（または両方の Wi-Fi がオンで近くにいるか）。iPhone の 設定 → プライバシーとセキュリティ → ローカルネットワーク で MacRemote が許可されているか |
| つながるが画面が黒いまま | Mac で「画面収録」が許可されているか。Mac のメニューの「登録済みの端末と設定…」のログ |
| 画面は映るが操作できない | Mac で「アクセシビリティ」が許可されているか |
| 「鍵が登録したときと違う」と出る | Mac 側で鍵を作り直した可能性があります。iPhone の一覧から削除し、もう一度 QR コードで登録してください |

不具合を見つけたら、Mac のログ（設定画面の下）と、iPhone のツールバーの fps と遅延の値を一緒に教えてください。
