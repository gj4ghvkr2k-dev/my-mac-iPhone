# 要件定義 v2

iPhone／iPad から Mac をリモート操作するアプリ（仮称：MacRemote）の要件です。

## 1. 前提

| 項目 | 内容 |
|---|---|
| 操作される側（ホスト） | Mac（macOS 14 以上を推奨） |
| 操作する側（クライアント） | iPhone／iPad（iOS／iPadOS 17 以上を推奨） |
| 利用者 | 自分と家族 |
| 配布 | iOS は TestFlight。Mac は自分でビルドするか、公証済みアプリとして配る |
| 操作できる範囲 | Mac にログインしたあとの画面だけ（ログイン画面は対象外） |
| 開発の進め方 | コードは主に Claude が書き、オーナーが Mac の Xcode でビルドと実機確認をする |

## 2. 接続方式

| 場面 | 方式 | 段階 |
|---|---|---|
| 自宅の LAN | Bonjour で相手を自動で見つけ、直接つなぐ | 第1段階 |
| ルーターなしの直接接続 | AirDrop と同じ仕組みの Wi-Fi 直結（AWDL）でつなぐ | 第1段階 |
| ルーターなしの直接接続 | USB ケーブルでつなぐ | 第3段階 |
| 外出先から | 小さなサーバーが接続を仲介し、つながったあとは端末同士で直接通信する。<br>直接つながらないときは中継サーバーを経由する | 第3段階 |

## 3. 機能

### 3.1 画面の操作（第1段階）

**操作モード**
- iPhone の初期値はトラックパッドモードです。画面全体をトラックパッドのように使い、指の動きに合わせてカーソルが動きます。
- iPad の初期値は直接タッチモードです。触った位置を直接クリックします。
- どちらのモードにも、ワンタップで切り替えられます。

**ジェスチャー**

| ジェスチャー | 動作 |
|---|---|
| 1本指タップ | 左クリック |
| 2本指タップ | 右クリック |
| 2本指ドラッグ | スクロール |
| 長押ししてから動かす | ドラッグ |
| ピンチ | 手元の画面だけを拡大・縮小する（Mac 側の表示は変わらない） |
| 3本指で左右にスワイプ | デスクトップ（操作スペース）を切り替える |
| 3本指で上にスワイプ | Mission Control を開く |

**キーボード**
- 特殊キーのバーを付けます：⌘ ⌥ ⌃ ⇧ Esc fn F1〜F12 と矢印キー。
- ⌘Space（Spotlight）などのショートカット用ボタンも付けます。
- 日本語は iPhone 側で変換し、確定した文字列を Mac へ送ります。

**画面表示**
- 遅延を優先します。目標は LAN で 50ms 以下、インターネット越しで 150ms 以下です。
- 基本は 60fps です。回線が細いときは画質を自動で下げます。
- モニターが複数あるときは、表示するモニターを切り替えられます。

**iPad 向け**
- 外付けキーボード、トラックパッド、Apple Pencil で操作できるようにします。

### 3.2 追加機能（第2段階）

| 機能 | 内容 |
|---|---|
| クリップボードの共有 | コピーした文字を Mac と iPhone の間でやり取りする。iOS の仕様上、iPhone 側で貼り付けるたびに許可の確認が出ることがある |
| ファイル転送 | Mac と iPhone／iPad の間でファイルを送受信する |
| 音声転送 | Mac で鳴っている音を iPhone で聞く（ScreenCaptureKit で取り込む） |

### 3.3 電源操作（第4段階）

- スリープ、再起動、シャットダウンができます。
- スリープ中の Mac を起こす機能は、LAN 内からの利用が前提です。Mac の「ネットワークアクセスによってスリープを解除」を使います。
- 外出先から起こすには、自宅に常時動いている機器（Apple TV、HomePod、Raspberry Pi など）が必要です。

## 4. セキュリティ

- 最初の1回だけ QR コードで端末を登録します。
- 登録していない端末はつながりません。
- 通信は常に暗号化します。
- 一度登録した端末は、接続のたびに Mac 側で許可しなくてもつながります。
- 接続中は、Mac のメニューバーのアイコンで分かるようにします。
- 1台の Mac につながるのは、同時に1台だけです。別の端末がつなぐと、前の接続は切れます。
- 登録した端末は、Mac 側の一覧から削除できます。

## 5. 開発の段階

| 段階 | 内容 |
|---|---|
| 第1段階 | LAN 内と Wi-Fi 直結で、画面表示、マウス・キーボード操作、QR コードでの端末登録まで |
| 第2段階 | クリップボードの共有、ファイル転送、音声転送 |
| 第3段階 | 外出先からの接続（仲介・中継サーバー）と USB 接続 |
| 第4段階 | 電源操作、操作感と画質の調整 |
